# Simple Scheduler

This is a simple scheduler program meant to showcase how a CPU schedules multiple ongoing processes. To showcase this, I'm creating a sandbox simulting multiple entities with different behaviors. Currently (9/30),
I'm writing this using Rust with Macroquad (_v. 0.4.16_), and I'll be simulating multiple hamsters, all with different behaviors. As a stretch goal, I'd like to add a GUI, some user controls, and 3D visuals.
